# 决策方法 · EPIC 场景指引

从 186 篇「决策方法」研究论文里提炼出的决策指南：把抽象的学术方法（前景理论、后悔理论、多准则决策、群决策共识、双边匹配、应急决策、SWOT、数据驱动、帕累托、三支决策），翻译成**生活、学习、工作、交际、娱乐、商业、会议、项目、爱情、关系**十大场景下的 E-P-I-C 决策指引。

## 四大板块

- **方法库**：10 种决策方法，一句话本质 + 通俗解释 + 适用场景 + 文献溯源
- **场景指引**：10 大场景，每个含 E（本质矛盾）· P（推荐方法）· I（具体做法）· C（边界警示）+ 一道实战选择题（即时反馈）
- **五步演练**：决策五步法通用流程 + 「要不要换工作」实战演示
- **决策风格**：8 题测出你的决策风格（数据驱动 / 直觉行动 / 风险规避 / 共识协商），给出优势、盲点与行动建议

## 核心框架

- **E-P-I-C**：Essence 本质洞察 → Pattern 模式提炼 → Implication 意涵衍生 → Context 语境重构
- **决策五步法**：定本质 → 列选项 → 定标准 → 权衡推演 → 拍板设界
